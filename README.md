### ⚡ QuantMind: High-Speed Mental Math & Calculation Trainer 🧠

*Sharpen your mental agility, calculation speed and numerical pattern recognition.*

<a href="https://mudittejra.github.io/QuantMind/">
  <img src="https://img.shields.io/badge/▶%20PLAY%20LIVE-QuantMind-00c853?style=for-the-badge&logo=googlechrome&logoColor=white" />
</a>
<a href="https://github.com/MuditTejra/QuantMind">
  <img src="https://img.shields.io/badge/VIEW%20SOURCE-GitHub-181717?style=for-the-badge&logo=github&logoColor=white" />
</a>

</div>

| | |
|---|---|
| 🎮 **What it does** | Shows 3 math expressions per round. Solve them in your head and click them in **ascending order**. |
| 📈 **Difficulty** | 5 phases: addition/subtraction → multiplication → division → squares → cubes & mixed |
| ⚡ **Feedback** | Instant visual and audio cues powered by Tone.js |
| 🛠️ **Built with** | HTML5 · CSS3 · Vanilla JavaScript · Tone.js |
| 🌐 **Live** | **[mudittejra.github.io/QuantMind](https://mudittejra.github.io/QuantMind/)** |
